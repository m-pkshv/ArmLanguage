# Այբուբեն — армянский алфавит

Веб-приложение для изучения армянского алфавита для русскоговорящих.

## Возможности

- **Алфавит**: все 39 букв (восточноармянская норма) с названием, звуком, примером слова и подсказками про трудные звуки.
- **Карточки**: вспомнить букву, перевернуть карточку, отметить «помню» или «не помню».
- **Тест**: три режима: «буква → звук», «звук → буква», «прочитай слово». Неправильные варианты подбираются из похожих букв (Տ/Թ, Ռ/Ր, Ո/Օ…).
- Буквы можно учить группами (1–10, 11–20…), отдельно повторять похожие и невыученные.
- Буква считается выученной после 3 правильных ответов подряд. Прогресс хранится в браузере (localStorage).

## Запуск локально

```bash
python -m http.server 8765
```

Затем откройте http://localhost:8765.

## Публикация на GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)`.

## Структура

- `index.html` — разметка
- `css/style.css` — стили
- `js/data.js` — данные о буквах (здесь удобно править примеры и подсказки)
- `js/app.js` — логика
