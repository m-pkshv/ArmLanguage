# Այբուբեն — армянский язык для русскоговорящих

Бесплатное веб-приложение для изучения армянского языка. Первый раздел — алфавит: уроки, задания,
интервальное повторение. Работает на телефоне и компьютере, без регистрации.

- **Сайт:** https://m-pkshv.github.io/ArmLanguage/ — приложение (в разработке)
- **Прототип v0.1:** https://m-pkshv.github.io/ArmLanguage/old/
- **Документация:** [docs/](docs/README.md) — концепция, функционал, задания, контент, архитектура, план

## Структура

| Папка | Что там |
|---|---|
| `src/` | новое приложение (Svelte + TypeScript), см. [архитектуру](docs/06-architecture.md) |
| `tests/` | автоматические тесты |
| `legacy/` | прототип v0.1, публикуется по адресу `/old/` |
| `docs/` | документация проекта |
| `.github/workflows/` | автоматическая проверка и публикация на GitHub Pages |

## Разработка

Нужен Node.js 22 или новее.

```bash
npm install
```
```bash
npm run dev
```

Приложение откроется на http://localhost:5173. Остальные команды:

- `npm test` — тесты;
- `npm run check` — проверка типов;
- `npm run build` — сборка в папку `dist/`.

При каждом изменении ветки `main` GitHub Actions проверяет код и публикует сайт.
