# CLAUDE.md — правила работы с проектом

Веб-приложение для изучения армянского языка русскоговорящими. Первый раздел — алфавит.
Сайт: https://m-pkshv.github.io/ArmLanguage/ · репозиторий: https://github.com/m-pkshv/ArmLanguage

## Общение с владельцем

- Только на **русском**, простым языком, без программистского жаргона: владелец не программист и
  доверяет технические решения. Спрашивать стоит только о продукте и контенте.
- Работаем через документацию: крупные изменения сначала описываются в `docs/`, потом делаются.
- Каждое новое задание или экран выпускается отдельно, после проверки на экране размером с телефон.
- **Не делать:** напоминания и уведомления о занятиях (решено не делать совсем).
- **Картинки к словам — пиктограммы ARASAAC, лицензия только некоммерческая.** Если зайдёт речь о монетизации
  (реклама, платные функции, продажа), сначала напомнить владельцу: картинки ARASAAC нужно заменить
  (см. `docs/04-content.md`, 4.5). Новые картинки — `npm run images -- search <слово>` / `set <id> <номер>`.
- **Отложено до отдельного решения:** звуки букв, форма «Сообщить об ошибке» и GoatCounter
  (код готов, включается в `src/config.ts`), проверка контента носителем (Google-таблица).

## Команды

Node.js установлен в `C:\Program Files\nodejs` и может отсутствовать в PATH оболочки Bash:
`export PATH="/c/Program Files/nodejs:$PATH"`.

```bash
npm run dev            # http://localhost:5173 (или предпросмотр "app" из .claude/launch.json)
npm test               # все тесты, включая проверку контента
npm run check          # проверка типов Svelte/TypeScript (без ошибок и предупреждений)
npm run check:content  # только проверка контента
MSYS_NO_PATHCONV=1 BASE_PATH=/ArmLanguage/ npm run build   # сборка как на GitHub
```

В Git Bash без `MSYS_NO_PATHCONV=1` путь `/ArmLanguage/` превращается в путь Windows — сборка ломается.

## Как устроен код (кратко)

- `content/` — учебные данные (JSON). `src/core/` — чистая логика без интерфейса (прогресс, повторение,
  проверка ответов, армянский текст, уроки, пары). `src/exercises/` — задания: логика (`*.ts`, реестр
  `logic.ts`) и вид (`views/*.svelte`, реестр `registry.ts`). `src/session/` — состав занятий (`plan.ts`),
  выбор задания (`select.ts`), ход (`run.ts`), «Продолжить» (`next.ts`), запуск (`start.ts`).
  `src/app/` — экраны и состояние, `src/ui/` — общие компоненты.
- Все тексты интерфейса — в `src/i18n/ru.json` (функция `t()`), не в компонентах.
- Прогресс хранится в localStorage (`hy:progress`), схема с версией: при изменении формата — повысить
  `SCHEMA_VERSION` и добавить миграцию в `src/core/progress/schema.ts` (+ тест).
- Новый тип задания: id в `src/core/session/types.ts` → логика + `logic.ts` → вид + `registry.ts` →
  таблица выбора в `src/session/select.ts` и/или список «Своей тренировки» → тесты → `docs/03-exercises.md`.
- **Правило для заданий со словами:** пользователь ещё не знает армянских слов — показывать чтение слова
  по буквам (`readingOf` в `src/core/text/armenian.ts`) и перевод; варианты с одинаковым чтением исключать.
- Комментарии в коде — на русском, в стиле существующих; ссылки на разделы документации приветствуются.

## Проверка перед публикацией

1. `npm test` и `npm run check` — без ошибок.
2. Посмотреть изменение в браузере в размере телефона (375×812), светлая и тёмная тема.
   В режиме разработки есть `window.__session` (`current()`, `answer()`, `next()`, `intro()`) для
   автоматического прохождения занятий. Занятия запускать кликами по интерфейсу и перезагружать страницу
   перед проверкой: модули, импортированные из консоли, после горячей перезагрузки бывают устаревшими.
3. Убрать тестовые данные из localStorage браузера.

  GitHub Pages (приложение в корне, прототип `legacy/` — в `/old/`). Дождаться зелёной сборки и проверить сайт.
- У приложения офлайн-кэш: пользователи видят новую версию после кнопки «Обновить» (или перезапуска).
- Коммиты — **только от `Maksim Pekshev <pekshev.m@gmail.com>`** (задано в локальном git config
  репозитория). Рабочую почту компьютера не использовать.
- Сообщения коммитов — на русском, с кратким списком изменений.
