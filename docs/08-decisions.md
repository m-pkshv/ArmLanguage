# 8. Решения

Принятые решения и то, что ещё осталось решить. При изменении решения — обновить строку и документ, на который она ссылается.

| 24 | Качество вариантов в словах | Синонимы (`same`: մամա/մայր, спасибо/մերսի) и фразы, подходящие к той же ситуации (`alsoFits`), не бывают неправильным вариантом; в теме у слов нет одинаковых картинок; урок темы — не длиннее 26 заданий | [10-first-words.md](10-first-words.md) |
| 25 | Следующие шаги (2026-09-28) | Сначала связать разделы и выпустить 1.0 (главный экран → слова, общее повторение, версия), параллельно — проверка на телефонах, носитель, звуки; потом «Чтение», новые темы, «Фразы», новые задания для алфавита | [этап 6](07-roadmap.md#этап-6-следующие-шаги-план-от-2026-09-28) |
| 26 | «Продолжить» после алфавита | Ведёт в «Первые слова»: следующий урок первой незаконченной темы → итоговое задание темы; итоговый тест алфавита и задания тем предлагаются один раз, не сдано — кнопка ведёт дальше (пересдать — на карте уроков / экране темы) | [9.4](09-navigation.md#94-главный-экран-учить) |
| 27 | Общее повторение и версия 1.0 | Одна кнопка «Повторить (N)» для букв и слов (до 30 заданий, самые «просроченные» первыми), своя кнопка слов в разделе остаётся; версия 1.0 и окно «Что нового» один раз после обновления, только тем, кто уже занимался | [10.6](10-first-words.md#106-уроки-практика-повторение), [9.16](09-navigation.md#916-версия-и-что-нового) |
| 28 | Новые темы слов 13–16 | «Животные», «Чувства и настроение», «Работа и учёба», «Путешествия» — по одной за выпуск; слово входит только в одну тему (без повторов между темами); слова без подходящей картинки — без картинки; «Я из России» — во фразах «Путешествий» | [10.3](10-first-words.md#103-темы) |
