(см. [метки версий](02-features.md#метки-версий)).

## Этап 1. Каркас
- [x] Проект Vite + TypeScript + Svelte, структура папок по [архитектуре](06-architecture.md)
- [x] GitHub Actions: проверки + публикация на Pages (приложение — в корне сайта, прототип — в `/old/`)
- [x] Мобильный каркас: нижняя навигация, адреса экранов, темы, настройки
- [x] Хранилище прогресса со схемой версий и миграциями, резервная копия в файл, предупреждение для режима «инкогнито»
- [x] Лицензии (`LICENSE`, `CONTENT-LICENSE.md`), страница «О проекте» с описанием приватности
- [x] Автоматические тесты: прогресс, резервная копия, адреса экранов
- **Готово, когда:** пустое приложение с навигацией открывается по адресу на GitHub Pages на телефоне.

## Этап 2. Контент (параллельно с этапом 1)
- [ ] Google-таблица контента и скрипт `content:pull`, валидация
- [ ] Буквы: названия, звуки, подсказки для 39 букв
- [ ] Банк слов: 3–5 примеров на букву + ~200 слов для чтения, с произношением (непроизносимое «ы») и исключениями
- [ ] Картинки для слов-примеров (Twemoji, запасные — OpenMoji), страница «Авторы и лицензии»
- [ ] Рукописные буквы: скачать набор с Wikimedia Commons, **разрезать на заглавные и строчные**, проверить наличие Ու
- [ ] Звуки 39 букв: найти свободные записи или записать у носителя
- [ ] Русские слова для задания «вставь букву»
- **Готово, когда:** валидация проходит без ошибок, у каждой буквы есть слова с картинками и рукописная форма.

- [ ] Движок занятий и интервальное повторение
- [ ] Задания: E01 знакомство, E02 буква → звук, E03 звук → буква, E15 заглавная ↔ строчная,
      E04 картинка → буква, E06 карточка с вводом + экранные клавиатуры, E08 вставь букву в русское слово
- [ ] 8 уроков не по алфавиту, карта уроков, главный экран «Продолжить», первый запуск
- [ ] Итоги занятия и урока, выход и продолжение с места остановки
- [ ] Практика: «Повторение», «Своя тренировка»
- [ ] Итоговый тест (≥ 90%)
- [ ] Работа офлайн, установка на главный экран
- [ ] «Сообщить об ошибке», анонимная статистика посещений
- [ ] **Проверка контента носителем** в Google-таблице, исправления
- [ ] Проверка на реальных телефонах (iPhone Safari, Android Chrome)
