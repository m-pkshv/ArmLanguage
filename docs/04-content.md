# 4. Контент

Учебный материал хранится **отдельно от кода**. Его ведут в **Google-таблице**, которую удобно
редактировать без программирования, а скрипт превращает её в файлы данных для приложения
(см. [4.9](#49-как-ведётся-контент)). Автоматическая проверка ([4.8](#48-валидация-контента)) не даст выложить сломанные данные.
Ниже показан формат, в котором данные попадают в приложение.

## 4.0 Состав алфавита

**Решение:** изучаем **39 букв** современного восточноармянского алфавита (реформированная орфография Армении):
- 36 букв Месропа Маштоца, кроме Ւ, плюс Օ и Ֆ, добавленные позже;
- **Ու ու** считается отдельной буквой (звук «у»), хотя пишется двумя знаками;
- **և** — отдельная буква («ев»), у неё нет заглавной формы: в начале предложения пишут «Եվ», в тексте
  заглавными буквами — «ԵՎ»;
- **Ւ ւ** отдельно не изучается: в современной орфографии она встречается только внутри ու и (исторически) և.
  Упоминается в карточке Ու.

Заглавная форма ու в таблицах и заданиях — **«Ու»** (в тексте заглавными буквами — «ՈՒ»).

Алфавитный порядок: Ա Բ Գ Դ Ե Զ Է Ը Թ Ժ Ի Լ Խ Ծ Կ Հ Ձ Ղ Ճ Մ Յ Ն Շ Ո Չ Պ Ջ Ռ Ս Վ Տ Ր Ց Ու Փ Ք և Օ Ֆ.

> **Проверить с носителем:** место և и Ու в алфавитном порядке (в разных букварях различается) и русские
> названия букв (особенно Ե, Յ).

## 4.1 Буква

```jsonc
// content/alphabet/letters.json — фрагмент
{
  "id": "tho",                      // стабильный латинский id, не меняется никогда
  "upper": "Թ", "lower": "թ",
  "order": 9,                       // место в алфавите
  "name": { "hy": "թո", "ru": "тхо" },
  "sound": {
    "ipa": "tʰ",
    "ru": "«т» с придыханием",
    "canonical": "тх",              // эталон для заданий с вводом
    "accept": [],                   // тоже полностью верно
    "partial": ["т"]                // «почти» (засчитывается в мягком режиме)
  },
  "notes": ["После «т» идёт лёгкий выдох, как будто задуваете свечу. Пара без придыхания — Տ."],
  "confusable": { "sound": ["tyun"], "shape": [] },
  "words": ["tutt", "trchun", "tev"],   // id слов-примеров, первое — главное
  "handwriting": { "upper": "img/handwriting/tho-upper.svg", "lower": "img/handwriting/tho-lower.svg" },
  "audio": null                     // V1: "audio/letters/tho.mp3" — после записи у носителя
}
```

## 4.2 Слово

```jsonc
// content/words/words.json — фрагмент
{
  "id": "khndzor",
  "hy": "խնձոր",
  "pronunciation": "хындзор",       // как звучит в речи (с непроизносимым «ы», см. 4.3a)
  "letterwise": "хндзор",           // буква за буквой — генерируется автоматически
  "exception": false,               // true — читается не по общим правилам, произношение задано вручную
  "reading": { "accept": [], "partial": [] },  // дополняются автоматически, вручную — только особые случаи
  "ru": "яблоко",
  "pos": "noun",
  "image": { "file": "img/words/apple.svg", "source": "Twemoji", "license": "CC BY 4.0" },
  "audio": null,                    // произношение слов — позже
  "tags": ["food"],
  "level": 1,                       // 1 — очень частое/простое слово
  "reviewed": false                 // проверено носителем
}
```

- Буквы, из которых состоит слово, **вычисляются автоматически**. Это нужно, чтобы давать на чтение
  только слова из уже изученных букв и подсвечивать изучаемую букву.
- Одно слово может быть примером для нескольких букв.
- Слова переиспользуются будущими разделами («Первые слова», «Словарь»).

### Правила подбора слов-примеров
1. У каждой буквы **3–5 слов**, хотя бы одно **начинается** с этой буквы (кроме Ղ и Ը,
   с которых слова начинаются редко). Остальные — с буквой в середине или конце.
2. Слова **изобразимые**: предметы, животные, еда, природа (для картинки). Абстрактные слова допустимы
   как дополнительные, без картинки.
3. Частые и полезные слова, по возможности — «слова-победы» (интернационализмы: ֆուտբոլ, տաքսի).
4. Для заданий на чтение нужен **банк слов ~200 шт.**, чтобы после каждого урока было достаточно слов
   только из изученных букв.
5. Все слова и чтения **проверяются носителем языка** перед публикацией (поле `reviewed: true`).

### 4.3a Непроизносимое «ы» и исключения

- **Непроизносимое «ы».** Между согласными часто звучит краткий гласный [ə], который не пишется:
  `խնձոր` [хындзор], `գրել` [гырел], `թռչուն` [тхырчун]. У каждого слова хранится произношение
  (`pronunciation`). Карточка слова показывает именно его, а задания на ввод принимают и произношение,
  и чтение буква за буквой (см. [правила проверки ввода](03-exercises.md#правила-проверки-ввода)).
  В карточке буквы Ը есть объяснение этого явления.
- **Исключения.** Слова, которые читаются не по общим правилам, помечаются `exception: true`, произношение
  задаётся вручную. Пример: формы глагола «быть» եմ [эм], ենք [энк], եք [эк], են [эн] — Ե в начале слова
  здесь не «йе». Список исключений ведётся на отдельном листе таблицы и проверяется носителем.
- Автоматическая расстановка «ы» надёжна не на 100%, поэтому произношение всех слов проверяет носитель.

> Для букв с одинаковым русским чтением (Խ/Հ = «х», Ո/Օ = «о», Ր/Ռ в мягком режиме) задания с вводом
> проверяют только звук. **Различение таких пар тренируют отдельно**: задания на выбор (E02, E03)
> и пары-ловушки (E10).

## 4.4 Порядок изучения

Порядок уроков **не алфавитный**: с первого урока можно читать настоящие слова. Пары похожих звуков
разнесены: сначала учится одна буква, позже — вторая и сразу задания на различение.

Для каждого урока валидатор контента считает, сколько слов из банка уже можно прочитать.
Эта цифра показывается на карте уроков.

**Черновик (слова требуют проверки носителем):**

| Урок | Буквы | Какие слова уже можно прочитать |
|---|---|---|
| 1 | Ա Մ Ն Տ Ս | մամա (мама), տատ (бабушка), նա (он/она), սա (это), Աննա |
| 2 | Ի Ր Ո Ու Կ | տուն (дом), կատու (кошка), ոսկի (золото), սիրտ (сердце), իմ (мой) |
| 3 | Ե Լ Բ Դ Վ | լավ (хорошо), վարդ (роза), դաս (урок), բան (вещь), դու (ты) |
| 4 | Գ Զ Յ Հ Պ | Հայաստան (Армения), հայ (армянин), մայր (мать), լույս (свет), զանգ (колокол), պանիր (сыр) |
| 5 | Թ Փ Ք Չ Ճ | քար (камень), գիրք (книга), չորս (четыре), ճանապարհ (дорога) + пары Տ/Թ, Պ/Փ, Կ/Ք |
| 6 | Ծ Ձ Ջ Ժ Շ | ծով (море), ձուկ (рыба), ջուր (вода), ժամ (час), շուն (собака) |
| 7 | Խ Ղ Ռ Ը Է | խնձոր (яблоко), աղ (соль), դուռ (дверь), ընկեր (друг), էջ (страница) |

## 4.5 Картинки

**Решение:** основной источник — **Twemoji** (SVG, лицензия **CC BY 4.0**), для недостающих предметов —
**OpenMoji** (CC BY-SA 4.0) и Wikimedia Commons. Файлы хранятся в репозитории (`public/img/words/`),
позже любую картинку можно заменить на собственную иллюстрацию: в контенте меняется только путь к файлу.

| Источник | Лицензия | Что требуется | Роль |
|---|---|---|---|
| [Twemoji](https://github.com/jdecked/twemoji) (поддерживаемая версия jdecked) | графика — CC BY 4.0, код — MIT | указать авторство | **основной**: ~3700 ярких узнаваемых картинок |
| [OpenMoji](https://openmoji.org/) | CC BY-SA 4.0 | указать авторство; изменённые картинки распространять под той же лицензией | запасной, если в Twemoji нет нужного предмета |
| [Wikimedia Commons](https://commons.wikimedia.org/) | разные (проверять у каждого файла) | по лицензии файла | редкие предметы |
| Системные эмодзи | — | — | **не используем**: на разных телефонах выглядят по-разному, часть не отображается |

- Смешивать стили на одном экране нежелательно, поэтому запасные источники используем только при необходимости.
- У каждой картинки в контенте указаны источник, лицензия и автор. Страница «Авторы и лицензии»
  собирается автоматически и доступна из «Профиля» и подвала сайта.
- Картинка должна однозначно подсказывать слово («яблоко», а не «фрукт»). Где подходящий значок есть,
  он ставится и для отвлечённых слов (хорошо 👍, да ✅, нет ❌, что ❓).
- **На будущее:** для 21 слова картинки пока нет (он/она, это, мой, есть, куда, гранат, сахар…) — владелец
  просит найти способ их добавить (см. [план](07-roadmap.md#этап-4-версия-v2--раздел-алфавит-10)).
- Слова-примеры подбираются с учётом того, есть ли для них картинка.

## 4.6 Рукописный вариант

Армянская рукописная (школьная) форма у ряда букв заметно отличается от печатной, поэтому её
нужно учить отдельно.

**Решение:** образец — набор
[«Armenian handwritten upper- and lower-case pairs with font lines»](https://commons.wikimedia.org/wiki/Category:Armenian_handwritten_upper-_and_lower-case_pairs_with_font_lines)
на Wikimedia Commons.
- 39 SVG-файлов: заглавная и строчная буква в стиле школьной прописи, на разлиновке, в едином стиле
  (включая и `Եւ`). Эти изображения используются в статьях Википедии об армянском алфавите.
- Лицензия **CC BY-SA 4.0**, автор — участник Commons «そらみみ», более поздние версии файлов загрузил участник
  Kwamikagami; в подписи указываем обоих. Нужно указывать авторство. Если мы
  изменяем файлы (перекрашиваем, разбиваем на штрихи), изменённые версии тоже публикуются под CC BY-SA 4.0.
  На лицензию кода приложения это не влияет.
- Использование: карточка буквы, таблица алфавита в режиме «рукописные», задания E05 и E11,
  рукописный режим в других заданиях.
- **Подготовка файлов:** в исходных файлах заглавная и строчная нарисованы вместе на одной разлиновке.
  Чтобы показывать их по отдельности, каждый файл разрезается на два (`public/img/handwriting/<id>-upper.svg`,
  `<id>-lower.svg`). **Сделано** (этап 2): 77 файлов; у և только строчная — заглавной в наборе нарисована
  старая форма «Եւ», в современном языке её нет. Буквы нарисованы линиями, что пригодится для анимации прописи.
  Это производная работа: указываем автора оригинала и публикуем под той же лицензией CC BY-SA 4.0.
- Ограничения: это изображения, а не шрифт, поэтому рукописно показываются **отдельные буквы**, но не слова.
  Порядок штрихов в наборе не указан.
- `Ու` в наборе есть. **Проверить с носителем:** совпадают ли формы с современными прописями Армении.

**Рукописные слова (если понадобятся):** бесплатный шрифт
[Tumanian's Handwriting](https://fonter.am/en/fonts/tumanian-dzeragir) (почерк Ованеса Туманяна,
автор шрифта — Рубен Тарумян). Он бесплатен для личного и коммерческого использования, но это не открытая
лицензия, и это личный почерк, а не школьная пропись. Поэтому шрифт годится как дополнение, а не как
основной образец. Лицензию на встраивание в сайт нужно подтвердить у автора.

**v2, пропись (E12):** для анимации и обводки нужны SVG с отдельными штрихами в правильном порядке.
Их рисуем на основе набора с Commons (производная работа, CC BY-SA 4.0). Сначала нужно проверить, не
нарисованы ли буквы в исходных файлах одной линией: тогда анимацию можно сделать почти без доработки.

## 4.7 Аудио

**V1 — звуки букв.** Половина трудностей алфавита — звуковые (придыхание, Ղ, два «р»), текстом их не передать.
- 39 коротких записей: звук буквы и её название («тх… — тхо»). Записывает тот же носитель, который
  проверяет контент: около 15 минут на телефон в тихой комнате.
- Готовые записи проверены (этап 2): полного набора звуков букв со свободной лицензией **нет** — в Lingua Libre
  записаны лишь отдельные буквы. Поэтому звуки букв записывает носитель.
- Для **произношения слов** (позже) подходит **Lingua Libre**: 3231 запись восточноармянских слов носителями
  (CC BY-SA), а всего на Wikimedia Commons — около 47 000 файлов армянского произношения.
- Если к выпуску V1 записей нет, кнопка 🔊 скрыта — приложение работает и без неё.

**Позже — произношение слов** (`assets/audio/words/<id>.mp3`) и задания на слух.

- Формат — `.mp3`, 10–30 КБ на файл. Путь: `public/audio/letters/<id>.mp3`.
- Синтез речи браузера **не используется**: армянский голос есть лишь на немногих устройствах.

## 4.8 Валидация контента

Проверка (`npm run check:content`, код — `src/core/content/validate.ts`; запускается в CI вместе с тестами) проверяет:
- у каждой буквы заполнены обязательные поля, `id` уникальны;
- у буквы 3–5 слов, и каждое слово действительно содержит эту букву;
- все файлы (картинки, SVG, аудио), на которые ссылается контент, существуют;
- у каждой картинки указаны источник и лицензия;
- для каждого урока хватает слов из изученных букв (от 10 слов; в первом уроке — от 5);
- каждая буква входит ровно в один урок;
- произношение слов согласуется с таблицей транскрипции и правилом непроизносимого «ы»
  (расхождение — предупреждение; для слов с `exception: true` не проверяется);
- в режиме «выпуск» в сборку не попадают слова без отметки `reviewed` (при разработке можно работать
  и с непроверенными).

## 4.9 Как ведётся контент

**Google-таблица** — главный источник контента: её удобно редактировать вам и носителю языка без программирования.

| Лист | Что в нём |
|---|---|
| Буквы | 39 строк: буква, название, звук, подсказки, похожие буквы, слова-примеры |
| Слова | банк армянских слов: слово, произношение, перевод, картинка, теги, исключение, «проверено» |
| Русские слова и фразы | для заданий «вставь букву» и смешанного чтения |
| Уроки | номер, буквы урока |
| Исключения | слова, читающиеся не по правилам |

- В каждом листе есть столбцы **«Проверено»** и **«Замечания носителя»** — проверка идёт прямо в таблице.
- Скрипт `npm run content:pull` скачивает таблицу, превращает её в файлы данных (`content/*.json`),
  проверяет ([4.8](#48-валидация-контента)) и сохраняет в репозиторий, где видна история изменений.
- Таблица принадлежит вашему Google-аккаунту; для скрипта открыт доступ «по ссылке, только чтение».
