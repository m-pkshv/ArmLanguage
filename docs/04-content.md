# 4. Контент

Весь учебный материал хранится как **данные** (JSON-файлы), отдельно от кода.
Добавить слово, картинку или новый урок можно без программирования. Автоматическая проверка контента
(см. [валидацию](#48-валидация-контента)) не даст выложить сломанные данные.

## 4.1 Буква

```jsonc
// content/alphabet/letters.json — фрагмент
{
  "id": "tho",                      // стабильный латинский id, не меняется никогда
  "upper": "Թ", "lower": "թ",
  "order": 9,                       // место в алфавите
  "name": { "hy": "թո", "ru": "тхо" },
  "sound": {
    "ipa": "tʰ",
    "ru": "«т» с придыханием",
    "canonical": "тх",              // эталон для заданий с вводом
    "accept": [],                   // тоже полностью верно
    "partial": ["т"]                // «почти» (засчитывается в мягком режиме)
  },
  "notes": ["После «т» идёт лёгкий выдох, как будто задуваете свечу. Пара без придыхания — Տ."],
  "confusable": { "sound": ["tyun"], "shape": [] },
  "words": ["tutt", "trchun", "tev"],   // id слов-примеров, первое — главное
  "handwriting": "assets/handwriting/tho.svg",
  "audio": null                     // v2: "assets/audio/letters/tho.mp3"
}
```

## 4.2 Слово

```jsonc
// content/words/words.json — фрагмент
{
  "id": "dzuk",
  "hy": "ձուկ",
  "reading": { "canonical": "дзук", "accept": [], "partial": [] },  // accept/partial дополняются автоматически
  "ru": "рыба",
  "pos": "noun",
  "image": { "file": "assets/img/words/fish.svg", "source": "OpenMoji", "license": "CC BY-SA 4.0", "author": "…" },
  "audio": null,
  "tags": ["animals", "food"],
  "level": 1                        // 1 — очень частое/простое слово
}
```

- Буквы, из которых состоит слово, **вычисляются автоматически**. Это нужно, чтобы давать на чтение
  только слова из уже изученных букв и подсвечивать изучаемую букву.
- Одно слово может быть примером для нескольких букв.
- Слова переиспользуются будущими разделами («Первые слова», «Словарь»).

### Правила подбора слов-примеров
1. У каждой буквы **3–5 слов**, хотя бы одно **начинается** с этой буквы (кроме Ղ и Ը,
   с которых слова начинаются редко). Остальные — с буквой в середине или конце.
2. Слова **изобразимые**: предметы, животные, еда, природа (для картинки). Абстрактные слова допустимы
   как дополнительные, без картинки.
3. Частые и полезные слова, по возможности — «слова-победы» (интернационализмы: ֆուտբոլ, տաքսի).
4. Для заданий на чтение нужен **банк слов ~200 шт.**, чтобы после каждого урока было достаточно слов
   только из изученных букв.
5. Все слова и чтения **проверяются носителем языка** перед публикацией (поле `reviewed: true`).

## 4.4 Порядок изучения

Порядок уроков **не алфавитный**: с первого урока можно читать настоящие слова. Пары похожих звуков
разнесены: сначала учится одна буква, позже — вторая и сразу задания на различение.

Для каждого урока валидатор контента считает, сколько слов из банка уже можно прочитать.
Эта цифра показывается на карте уроков.

**Черновик (слова требуют проверки носителем):**

| Урок | Буквы | Какие слова уже можно прочитать |
|---|---|---|
| 1 | Ա Մ Ն Տ Ս | մամա (мама), տատ (бабушка), նա (он/она), սա (это), Աննա |
| 2 | Ի Ր Ո Ու Կ | տուն (дом), կատու (кошка), ոսկի (золото), սիրտ (сердце), իմ (мой) |
| 3 | Ե Լ Բ Դ Վ | լավ (хорошо), վարդ (роза), դաս (урок), բան (вещь), դու (ты) |
| 4 | Գ Զ Յ Հ Պ Ց | հաց (хлеб), մայր (мать), լույս (свет), զանգ (колокол), պանիր (сыр) |
| 5 | Թ Փ Ք Չ Ճ | քար (камень), գիրք (книга), չորս (четыре), ճանապարհ (дорога) + пары Տ/Թ, Պ/Փ, Կ/Ք |
| 6 | Ծ Ձ Ջ Ժ Շ | ծով (море), ձուկ (рыба), ջուր (вода), ժամ (час), շուն (собака) |
| 7 | Խ Ղ Ռ Ը Է | խնձոր (яблоко), աղ (соль), դուռ (дверь), ընկեր (друг), էջ (страница) |
| 8 | Օ Ֆ և | օր (день), ֆուտբոլ (футбол), բարև (привет), արև (солнце) + итоговый тест |

## 4.5 Картинки

**Решение:** основной источник — **Twemoji** (SVG, лицензия **CC BY 4.0**), для недостающих предметов —
**OpenMoji** (CC BY-SA 4.0) и Wikimedia Commons. Файлы хранятся в репозитории (`assets/img/words/`),
позже любую картинку можно заменить на собственную иллюстрацию: в контенте меняется только путь к файлу.

| Источник | Лицензия | Что требуется | Роль |
|---|---|---|---|
| [Twemoji](https://github.com/jdecked/twemoji) (поддерживаемая версия jdecked) | графика — CC BY 4.0, код — MIT | указать авторство | **основной**: ~3700 ярких узнаваемых картинок |
| [OpenMoji](https://openmoji.org/) | CC BY-SA 4.0 | указать авторство; изменённые картинки распространять под той же лицензией | запасной, если в Twemoji нет нужного предмета |
| [Wikimedia Commons](https://commons.wikimedia.org/) | разные (проверять у каждого файла) | по лицензии файла | редкие предметы |
| Системные эмодзи | — | — | **не используем**: на разных телефонах выглядят по-разному, часть не отображается |

- Смешивать стили на одном экране нежелательно, поэтому запасные источники используем только при необходимости.
- У каждой картинки в контенте указаны источник, лицензия и автор. Страница «Авторы и лицензии»
  собирается автоматически и доступна из «Профиля» и подвала сайта.
- Картинка должна однозначно подсказывать слово («яблоко», а не «фрукт»). Для абстрактных слов
  (хорошо, это, мой) картинка не нужна.
- Слова-примеры подбираются с учётом того, есть ли для них картинка.

## 4.6 Рукописный вариант

Армянская рукописная (школьная) форма у ряда букв заметно отличается от печатной, поэтому её
нужно учить отдельно.

**Решение:** образец — набор
[«Armenian handwritten upper- and lower-case pairs with font lines»](https://commons.wikimedia.org/wiki/Category:Armenian_handwritten_upper-_and_lower-case_pairs_with_font_lines)
на Wikimedia Commons.
- 39 SVG-файлов: заглавная и строчная буква в стиле школьной прописи, на разлиновке, в едином стиле
  (включая и `Եւ`). Эти изображения используются в статьях Википедии об армянском алфавите.
- Лицензия **CC BY-SA 4.0**, автор — участник Commons «そらみみ». Нужно указывать авторство. Если мы
  изменяем файлы (перекрашиваем, разбиваем на штрихи), изменённые версии тоже публикуются под CC BY-SA 4.0.
  На лицензию кода приложения это не влияет.
- Использование: карточка буквы, таблица алфавита в режиме «рукописные», задания E05 и E11,
  рукописный режим в других заданиях. Файлы кладутся в `assets/handwriting/<id>.svg`.
- Ограничения: это изображения, а не шрифт, поэтому рукописно показываются **отдельные буквы**, но не слова.
  Порядок штрихов в наборе не указан.
- **Проверить при подготовке:** есть ли в наборе `Ու`; совпадают ли формы с современными прописями
  Армении (показать носителю языка или учителю).

**Рукописные слова (если понадобятся):** бесплатный шрифт
[Tumanian's Handwriting](https://fonter.am/en/fonts/tumanian-dzeragir) (почерк Ованеса Туманяна,
автор шрифта — Рубен Тарумян). Он бесплатен для личного и коммерческого использования, но это не открытая
лицензия, и это личный почерк, а не школьная пропись. Поэтому шрифт годится как дополнение, а не как
основной образец. Лицензию на встраивание в сайт нужно подтвердить у автора.

**v2, пропись (E12):** для анимации и обводки нужны SVG с отдельными штрихами в правильном порядке.
Их рисуем на основе набора с Commons (производная работа, CC BY-SA 4.0). Сначала нужно проверить, не
нарисованы ли буквы в исходных файлах одной линией: тогда анимацию можно сделать почти без доработки.

## 4.7 Аудио (v2)

- Записи носителя: каждая буква (название и звук) и каждое слово. Формат — `.mp3`/`.ogg`, ~10–30 КБ.
- Путь: `assets/audio/letters/<id>.mp3`, `assets/audio/words/<id>.mp3`.
- Синтез речи браузера **не используется** как основной источник: армянский голос есть на единицах устройств.

## 4.8 Валидация контента

Скрипт (`npm run check:content`, запускается и в CI перед публикацией) проверяет:
- у каждой буквы заполнены обязательные поля, `id` уникальны;
- у буквы 3–5 слов, и каждое слово действительно содержит эту букву;
- все файлы (картинки, SVG, аудио), на которые ссылается контент, существуют;
- у каждой картинки указаны источник и лицензия;
- для каждого урока хватает слов из изученных букв (например, не меньше 10 слов для чтения);
- чтения слов согласуются с таблицей транскрипции (предупреждение, а не ошибка).
