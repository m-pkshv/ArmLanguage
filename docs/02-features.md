# 2. Функционал

Метки приоритета: **[MVP]** — первый релиз раздела «Алфавит», **[v2]** — следующий этап, **[Идея]** — на обсуждение.

## 2.1 Главный экран [MVP]

- Кнопка **«Продолжить»** — запускает следующую сессию: новый урок и/или повторение.
- **«К повторению сегодня: N»** — сколько букв пора повторить (по интервальному повторению).
- Прогресс по разделу: «Выучено 12 из 39 букв», полоска и карта уроков.
- Карта разделов курса. Будущие разделы («Чтение», «Первые слова»…) видны как «скоро».
- [v2] Серия дней подряд и дневная цель (например, 20 заданий). Без штрафов за пропуск.

## 2.2 Раздел «Алфавит»

### Таблица алфавита [MVP]
- Все 39 букв в **алфавитном порядке**, для каждой: заглавная и строчная, транскрипция, название.
- Переключатель **«Печатные / Рукописные»**: показывает буквы печатным или рукописным шрифтом.
- Индикатор изученности на каждой букве (не начата / изучается / выучена).
- Фильтр: «все», «похожие», «невыученные», по уроку.

### Карточка буквы [MVP]
Открывается по нажатию на букву:
- Большая буква: печатная (заглавная + строчная) и **рукописная** рядом.
- Название буквы по-армянски и по-русски: `Ձ — «дза», ձա`.
- Звук: русское описание + IPA мелким шрифтом: «[дз] — слитно, как в слове „дзюдо“».
- Подсказка для русскоговорящих (если звука нет в русском, пары, особенности чтения).
- **3–5 слов-примеров с картинками**: картинка, слово по-армянски (изучаемая буква подсвечена),
  чтение русскими буквами, перевод. Буква может стоять в начале, середине или конце слова.
- «Похожие буквы»: ссылки на буквы, с которыми её путают (по звуку и по виду).
- [v2] Кнопка 🔊: произношение звука и слов (запись носителя).
- [v2] Анимация порядка написания рукописной буквы.
- Статистика по букве: сколько раз верно / ошибочно, когда следующее повторение.

### Уроки [MVP]
- Раздел разбит на ~8 уроков по 4–6 букв (см. [04-content.md](04-content.md#44-порядок-изучения)).
- Урок = знакомство с новыми буквами + сессия заданий разных типов.
- Следующий урок открывается, когда буквы текущего пройдены хотя бы на уровне «узнавание».
  Заблокированный урок можно открыть вручную («я уже знаю эти буквы»).
- В конце раздела — **итоговый тест** (все буквы, все типы заданий).

### Свободная практика [MVP]
Экран, где пользователь сам выбирает:
- **какие буквы**: урок, группу по алфавиту, «похожие», «трудные для меня», все;
- **какие типы заданий** (см. [каталог](03-exercises.md));
- **шрифт** в заданиях: печатный / рукописный / вперемешку;
- длину сессии: 10 / 20 / без ограничения.

## 2.3 Сессия заданий [MVP]
- Задания идут по одному, сверху — полоска прогресса сессии.
- После ответа — мгновенная проверка и объяснение:
  - верно → зелёный, короткое подтверждение, автопереход (можно отключить);
  - «почти» → жёлтый: засчитано частично, объяснено, что уточнить (например, «т» вместо «тх»);
  - неверно → красный, правильный ответ + чем выбранный вариант отличается от правильного.
- Ошибочные задания повторяются в конце той же сессии.
- Итог сессии: верно/всего, какие буквы вызвали трудности, кнопка «Повторить трудные».
- Типы заданий в сессии чередуются, сложность растёт вместе с уровнем знания буквы.

## 2.4 Прогресс и интервальное повторение [MVP]
- Для каждой буквы хранится уровень знания **по каждому навыку отдельно**:
  узнавание (выбор), воспроизведение (ввод), чтение в слове, рукописный вариант, [v2] на слух.
- Интервальное повторение по системе коробок Лейтнера: верный ответ переносит элемент в следующую
  коробку (интервал растёт: сегодня → 1 день → 3 → 7 → 16 → 35 дней), ошибка — на шаг-два назад.
- Буква считается **выученной**, когда по основным навыкам она в коробке ≥ 3.
- Экран **статистики** [v2]: прогресс по буквам (тепловая карта алфавита), самые частые путаницы
  («Տ ↔ Թ — 7 ошибок»), активность по дням.

## 2.5 Настройки [MVP]
- Тема: светлая / тёмная / системная.
- Размер букв: обычный / крупный.
- Автопереход после верного ответа: вкл/выкл.
- Строгость проверки ввода: «строго» (придыхание обязательно) / «мягко» (засчитывать «т» за «тх»).
- Показывать IPA: вкл/выкл.
- **Экспорт / импорт прогресса** в файл JSON; сброс прогресса.
- [v2] Звук: вкл/выкл, скорость.

## 2.6 Работа офлайн [MVP]
- Приложение устанавливается на телефон как PWA (иконка на экране, запуск без браузера).
- После первого открытия работает без интернета (контент, картинки, шрифты кэшируются).

## 2.7 Мои предложения сверх запрошенного

| Функция | Зачем | Приоритет |
|---|---|---|
| **Смешанное чтение** — русский текст, в котором изученные буквы заменены армянскими: «Մամա мыла рամу». С каждым уроком армянских букв в тексте больше | Быстро и весело тренирует чтение на знакомом языке; к концу раздела человек читает почти полностью армянскими буквами | MVP |
| **Пары-ловушки** — отдельный тренажёр для похожих по звуку (Տ/Թ, Ռ/Ր, Ո/Օ) и по виду (ո/ս, դ/ղ/պ, ե/է) букв | Это главный источник ошибок у начинающих | MVP |
| **Найди пары** (мини-игра на сопоставление) | Разнообразие, быстрый повтор 5–6 букв за раз | MVP |
| **Слова-интернационализмы** — ֆուտբոլ, տաքսի, կոմպյուտեր: прочитал и сам понял | Быстрые победы, мотивация | MVP (как часть слов) |
| **Пропись** — обвести рукописную букву пальцем по контуру, затем написать самому | Письмо закрепляет форму буквы лучше, чем просмотр | v2 |
| **Аудио** — записи носителя для каждой буквы и слова, задание «услышь → выбери» | Правильное произношение; синтез речи для армянского почти нигде не работает | v2 |
| **Скоростной раунд** — 60 секунд, сколько букв успеешь | Автоматизм чтения | v2 |
| **Экзамен-сертификат** в конце раздела — красивая страница «Я знаю армянский алфавит» | Мотивация, можно поделиться | Идея |
| **Армянская клавиатура** — подсказка, как включить её на телефоне/ПК, тренажёр набора | Пригодится для следующих разделов | Идея |
| **Синхронизация прогресса** между устройствами (вход через GitHub/Google) | Удобство, но требует серверной части | Идея |
