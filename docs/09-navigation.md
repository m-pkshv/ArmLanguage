# 9. Навигация и сценарии

Как пользователь перемещается по приложению: карта экранов, порядок переходов, поведение в уроке
и в особых ситуациях. Внешний вид экранов — в [05-ui-mobile.md](05-ui-mobile.md).

## 9.1 Правила навигации

1. **Одна главная кнопка на экране.** Она крупная и стоит внизу, в зоне большого пальца. Всё остальное вторично.
2. **До любого занятия — не больше 2 нажатий** с главного экрана.
3. **«Назад» работает всегда и предсказуемо**: кнопка ←, системный жест «назад» на iPhone и кнопка «назад» на Android.
   Во время урока «назад» равносилен ✕ (выход с подтверждением).
4. **Ничего не теряется.** Состояние урока сохраняется после каждого ответа. Если закрыть вкладку, позвонить или
   выключить экран, можно продолжить с того же места.
5. **Во время урока нет лишнего:** нижняя панель скрыта, только ✕, полоска прогресса и задание.
6. **Не спрашиваем того, без чего можно обойтись.** Регистрации нет, настроек при первом запуске нет, есть разумные значения по умолчанию.
7. **Каждый экран имеет адрес** (`#/...`), поэтому работают обновление страницы и ссылки.

## 9.3 Первый запуск

Цель — **первая армянская буква на экране меньше чем через 30 секунд.**

1. **Приветствие** (один экран): название, три строки «что вас ждёт» (буквы → слова → чтение;
   **алфавит за 2–3 недели по 10 минут в день**; работает без интернета), кнопка **«Начать с нуля»** и маленькая ссылка «Я уже знаю некоторые буквы».
2. «Начать с нуля» → сразу **урок 1**.
3. «Я уже знаю некоторые буквы» → карта уроков, где можно выбрать урок. Уроки до выбранного отмечаются как
   «пропущенные»: их буквы попадут в повторение, и если они действительно знакомы, быстро уйдут в «выучено».
   [Идея] Вместо этого — короткий тест на 15 заданий, который сам определит стартовый урок.
4. После первого урока — главный экран с подсказкой: «Возвращайтесь завтра — здесь будет видно, какие буквы пора повторить».
   Уведомлений и напоминаний приложение не присылает.

## 9.4 Главный экран «Учить»

```
┌─────────────────────────────┐
│ Այբուբեն              ⚙︎    │
│                             │
│  Урок 3 из 8                │
│  ▓▓▓▓▓▓▓▓░░░░░░  12/39 букв │
│  Можете прочитать 23 слова  │
│                             │
│ ┌─────────────────────────┐ │
│ │ К повторению: 8 букв    │ │
│ │ Ե Լ Բ Դ Վ …             │ │
│ └─────────────────────────┘ │
│                             │
│  Карта уроков           ›   │
│  Все разделы курса      ›   │
│                             │
│ ┌─────────────────────────┐ │
│ │      ПРОДОЛЖИТЬ         │ │ ← главная кнопка
│ └─────────────────────────┘ │
├─────────────────────────────┤
│ Учить  Алфавит Практ. Проф. │
└─────────────────────────────┘
```

**Что делает «Продолжить»** (решает приложение, пользователь не выбирает):

| Ситуация | Кнопка | Что запускается |
|---|---|---|
| Есть незаконченный урок | «Продолжить урок (7/20)» | тот же урок с того же места |
| К повторению ≥ 10 букв | «Повторить (12)» | сессия повторения |
| К повторению < 10 букв, есть новый урок | «Урок 4: Գ Զ Յ …» | новый урок; накопившиеся повторения вплетаются в него |
| Новых уроков нет, повторений нет | «Свободная практика» | переход в «Практику» |
| Раздел пройден | «Итоговый тест» → затем «Практика» | |

## 9.5 Карта уроков и экран урока

- **Карта уроков**: вертикальный список 8 уроков. У каждого — буквы урока, состояние (пройден ✓ / текущий /
  закрыт 🔒) и уверенность по его буквам. Внизу — «Итоговый тест».
- Нажатие на закрытый урок → «Сначала пройдите урок N» + кнопка «Я знаю эти буквы, открыть».
- **Экран урока** (перед началом): буквы урока крупно, «≈ 7 минут», какие слова откроются, кнопка **«Начать»**.
  Для пройденного урока — «Пройти ещё раз».

## 9.6 Порядок внутри урока

Урок — примерно **20–25 заданий, 5–8 минут**. Новые буквы вводятся **по 2**, чтобы не перегружать память:

```
┌ Разминка (со 2-го урока) по буквам прошлых уроков:
│   V1 — 3 быстрых задания «буква → звук»; V2 — мини-игра «Найди пары»
│
├ Знакомство: буква A (E01) → буква B (E01)
│   └ 4–6 заданий только на A и B: узнавание (E02, E03, E04)
│
├ Знакомство: буква C → буква D
│   └ 4–6 заданий на C и D + A и B вперемешку
│
├ (если есть 5-я буква) Знакомство: E → 2–3 задания
│
├ Закрепление: 6–8 заданий на все буквы урока + повторения
│   (ввод E06, вставь букву E08, прочитай слово E07, пары-ловушки E10 — по уровню)
│
├ Смешанное чтение (E09): 1–2 задания с новыми буквами
│
├ Прочитай слово (E07): одно слово из знакомых букв с новой буквой
│
└ Итоги урока
```

- Ошибки не останавливают урок: задание с ошибкой возвращается ближе к концу.
- Буква, в которой ошиблись 2 раза, после урока автоматически попадает в ближайшее повторение.

## 9.7 Цикл одного задания

```
Задание ──► ответ ──► проверка ──► панель результата ──► следующее задание
```

- **Панель результата** выезжает снизу и перекрывает клавиатуру и варианты:
  - ✓ зелёная: «Верно! Ձ — дза», кнопка **«Дальше»**. Автопереход через 1 сек (можно отключить в настройках);
  - ≈ жёлтая: «Почти: Թ — это „тх“, с придыханием», кнопка «Дальше»;
  - ✗ красная: правильный ответ + чем отличается выбранный вариант, кнопка **«Понятно»** (без автоперехода,
    чтобы успеть прочитать).
- В панели результата есть ссылки **«Карточка буквы»** (справка поверх урока, закрытие возвращает в урок)
  и **«Сообщить об ошибке»** (если, по мнению пользователя, задание или ответ неверны).
- «Не знаю» = показать ответ, засчитывается как ошибка.

```
┌─────────────────────────────┐
│           …задание…         │
├─────────────────────────────┤
│ ✗ Правильно: Թ — «тх»       │
│   Вы выбрали Տ — «т»,       │
│   без придыхания            │
│   Карточка буквы ›          │
│ ┌─────────────────────────┐ │
│ │        ПОНЯТНО          │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

## 9.8 Выход и возврат

- **✕ или «назад» во время урока** → окно «Выйти из урока? Ответы уже сохранены, продолжите с этого места».
  Кнопки: **«Продолжить урок»** (главная) / «Выйти».
- Прогресс по отвеченным заданиям **засчитан сразу**, незаконченный урок хранится до завершения.
- Если закрыть вкладку, при следующем открытии главный экран покажет «Продолжить урок (7/20)».
- Незаконченная **практика** (не урок) не хранится: выход = завершение с итогами по отвеченному.

## 9.9 Итоги урока и что дальше

```
┌─────────────────────────────┐
│         Урок 3 пройден!     │
│   Ե Լ Բ Դ Վ                 │
│   Верно 21 из 24            │
│   Теперь вы читаете 23 слова│
│   լավ · վարդ · դաս …        │
│                             │
│   Трудные: Ե (2 ошибки)     │
│                             │
│ ┌─────────────────────────┐ │
│ │   Урок 4: Գ Զ Յ Հ Պ Ց   │ │
│ └─────────────────────────┘ │
│   На главную                │
└─────────────────────────────┘
```

- Главная кнопка — **следующий урок**. Если за сегодня пройдено 2 урока, она становится «На главную»,
  а следующий урок предлагается ссылкой («Лучше закрепить завтра — но можно и сейчас»).
- Были ошибки → дополнительная ссылка «Потренировать трудные (2 мин)».
- Если урок открыл новую пару-ловушку → «Новая пара в тренажёре: Տ/Թ».

## 9.10 Алфавит (справочник)

- **Таблица** → нажатие на букву → **карточка буквы**.
- В карточке — свайп влево/вправо (или стрелки ‹ ›) к соседней букве **в алфавитном порядке**.
- Из карточки:
  - «Потренировать эту букву» → мини-сессия 8 заданий (буква + её пары-ловушки) → итоги → назад в карточку;
  - нажатие на похожую букву → её карточка (назад → вернуться);
  - нажатие на слово-пример → крупная картинка, слово с подсвеченной буквой, чтение.
- Невыученные буквы в таблице доступны: справочник открыт всегда, блокируются только уроки.

## 9.11 Практика

```
┌─────────────────────────────┐
│ Практика                    │
│ ┌───────────┐ ┌───────────┐ │
│ │Повторение │ │Пары-      │ │
│ │  8 букв   │ │ловушки  3 │ │
│ └───────────┘ └───────────┘ │
│ ┌───────────┐ ┌───────────┐ │
│ │Смешанное  │ │Найди пары │ │
│ │ чтение    │ │ рекорд 0:21│ │
│ └───────────┘ └───────────┘ │
│ ┌─────────────────────────┐ │
│ │ Своя тренировка       › │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

- Сейчас есть плитки «Повторение», «Пары-ловушки» (экран со списком пар, `#/practice/pairs`),
  «Смешанное чтение», «Прочитай слово» (обе — сразу 10 заданий) и «Своя тренировка». Плитка «Найди пары» появится в V2.
- Плитки запускаются **одним нажатием** с разумными настройками. Цифра на плитке показывает, сколько там
  «работы» (букв к повторению, путаемых пар).
- **Своя тренировка** — один экран с настройками: буквы (урок / по алфавиту / похожие / трудные / все),
  типы заданий, шрифт (печатный / рукописный / вперемешку), длина (10 / 20 / без ограничения) → «Начать».
  Последние настройки запоминаются.
- Практика доступна только по изученным буквам. Если изученных меньше 4, плитки неактивны с подсказкой
  «Пройдите первый урок».

## 9.12 Профиль

Список: Статистика [V2] · Настройки · Резервная копия (сохранить / загрузить) · Установить на главный экран ·
Авторы и лицензии · О проекте · Сбросить прогресс (с двойным подтверждением).

## 9.13 Подсказки на главном экране

Это подсказки внутри приложения, а не уведомления: они видны только при открытом приложении.
Появляются **не чаще одной за раз и не во время урока**, только на главном экране:

| Когда | Что |
|---|---|
| После 2-го урока, если приложение не установлено | «Установите на главный экран — так прогресс надёжнее сохранится» + инструкция для iPhone/Android |
| Раз в 7 дней, если копия не сохранялась | «Сохраните резервную копию прогресса» |
| Открыт новый урок | Короткое сообщение внизу экрана на 3 сек |
| Хранилище недоступно (например, режим «инкогнито») | Постоянная плашка: «Прогресс не сохранится после закрытия» |

## 9.14 Пустые и крайние состояния

| Ситуация | Что видит пользователь |
|---|---|
| Повторений на сегодня нет | «На сегодня всё повторено ✓» + кнопки «Новый урок» / «Поиграть в „Найди пары“» |
| Все уроки пройдены, итоговый тест не сдан | Главная кнопка «Итоговый тест» |
| Раздел полностью пройден | Поздравление, «Сертификат» [идея], раздел «Чтение» — «скоро» |
| Нет интернета при первом открытии | Сообщение «Нужен интернет для первой загрузки» (дальше работает офлайн) |
| Вышла новая версия приложения | Внизу: «Доступно обновление — Обновить». Во время урока не показывается |
| Импорт файла прогресса с ошибкой | «Файл не подходит» — текущий прогресс не меняется |
