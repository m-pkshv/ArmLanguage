# 5. Интерфейс и мобильная вёрстка

## 5.1 Принцип: сначала телефон

Интерфейс проектируется под телефон (ширина **360 px** и больше), затем расширяется для планшета и
компьютера. Все функции доступны на всех устройствах.

| Ширина | Раскладка |
|---|---|
| < 600 px (телефон) | одна колонка, **нижняя панель навигации**, клавиатура заданий прижата к низу экрана |
| 600–1024 px (планшет) | одна колонка шире, таблица алфавита в 6–8 колонок |
| > 1024 px (компьютер) | верхняя навигация, контент по центру (макс. ~960 px), горячие клавиши |

## 5.2 Требования к мобильной вёрстке

- **Размер нажимаемых элементов** — не меньше 44×44 px, отступы между кнопками вариантов ≥ 8 px.
- **Ничего не зависит от наведения мыши** (hover) — только нажатия.
- **Экранная клавиатура** в заданиях с вводом: своя, внутри страницы, системная не открывается
  (`inputmode="none"`). Подробности — в [5.7](#57-экранные-клавиатуры).
- **Безопасные зоны** iPhone (вырез, полоска «домой»): `env(safe-area-inset-*)`.
- Высота экрана — `100dvh`, чтобы адресная строка браузера не «прыгала» и не перекрывала кнопки.
- **Нет горизонтальной прокрутки** ни на одном экране.
- Шрифт интерфейса ≥ 16 px (иначе iOS увеличивает страницу при вводе); армянские буквы в заданиях — крупно (80–120 px).
- Портретная ориентация — основная; в альбомной ничего не ломается.
- Тактильный отклик (вибрация 10–20 мс) на верный/неверный ответ — где поддерживается, отключается в настройках.
- Анимации короткие (≤ 300 мс) и отключаются при системной настройке «уменьшить движение».
- Проверяется на: iOS Safari (iPhone SE и новее), Android Chrome, настольные Chrome/Firefox/Edge/Safari.

## 5.3 Навигация

Подробные сценарии переходов — в [09-navigation.md](09-navigation.md).

Нижняя панель на телефоне (верхняя — на компьютере):

```
┌────────┬──────────┬──────────┬──────────┐
│ Учить  │ Алфавит  │ Практика │ Профиль  │
└────────┴──────────┴──────────┴──────────┘
```

- **Учить** — главный экран: «Продолжить», повторение, карта уроков.
- **Алфавит** — таблица, карточки букв (справочник).
- **Практика** — свободная тренировка с выбором букв и заданий.
- **Профиль** — статистика, настройки, экспорт/импорт.

Во время сессии нижняя панель скрыта, сверху — «✕» и полоска прогресса сессии.

Адреса экранов (работают кнопки «назад» и ссылки):
`#/`, `#/alphabet`, `#/alphabet/tho`, `#/lesson/alphabet-3`, `#/practice`, `#/profile`, `#/settings`.

## 5.4 Схемы ключевых экранов (телефон)

**Задание с вводом (E06):**
```
┌─────────────────────────────┐
│ ✕  ▓▓▓▓▓▓░░░░░░░░   6 / 15  │
│                             │
│            Թ թ              │  ← буква, 100 px
│   Как читается эта буква?   │
│                             │
│     ┌───────────────┐       │
│     │  т х_         │       │  ← поле ответа
│     └───────────────┘       │
│  [Не знаю]      [Проверить] │
├─────────────────────────────┤
│ й ц у к е н г ш щ з х ъ     │  ← экранная клавиатура,
│ ф ы в а п р о л д ж э       │    прижата к низу
```

**Вставь армянскую букву (E08):**

```
│ ✕  ▓▓▓▓▓▓▓▓░░░░░░   8 / 15  │
│            🚗               │
│        м а [ ? ] и н а      │
│  Какая армянская буква      │
│  даёт звук «ш»?             │
│                             │
│   ┌─────┐ ┌─────┐           │
│   │  Շ  │ │  Չ  │           │
│   └─────┘ └─────┘           │
│   ┌─────┐ ┌─────┐           │
│   │  Ժ  │ │  Ս  │           │
│   └─────┘ └─────┘           │

```

**Карточка буквы:**
```
┌─────────────────────────────┐
│ ←                     ‹  ›  │
│   Ձ ձ      [рукописная Ձ ձ] │
│   «дза» · ձա   [дз]    🔊   │
│ ┌─────────────────────────┐ │
│ │ Слитное «дз», как в     │ │
│ │ слове «дзюдо».          │ │
│ └─────────────────────────┘ │
│  🐟 ձուկ   [дзук]   рыба    │
```

## 5.5 Визуальный стиль

- Три цветовые темы (выпуск 1.1, 2026-09-28) — у каждой светлый и тёмный вид; полное описание цветов, состояний
  и контраста — [11-design.md](11-design.md), макеты — `docs/design/Design.html` (в сайт не попадает).
- Зелёный — только успех и прогресс; красный — «неверно»; янтарный — только «почти». Акцент — действия и выбор.
- Контраст текста не ниже WCAG AA (4,5:1) — проверяется тестом для всех тем.
- Шрифты: интерфейс — Inter, армянский — Noto Sans Armenian, заголовки темы «Дилиджан» — Lora (все в офлайн-кэше);
  рукописный вариант — см. [04-content.md](04-content.md#46-рукописный-вариант).
- Цвет никогда не единственный признак: у верного ответа — ✓, у «почти» — ≈, у неверного — ✗.

### Цветовые темы

| Тема | id | Характер |
|---|---|---|
| **«Матенадаран»** — по умолчанию | `ink` | Почти монохром: «чернильные» кнопки (в тёмном виде — светлые «бумажные»), цвет только в смысле ответа. Ссылки подчёркнуты |
| «Севан» | `sevan` | Прохладный «каменный» фон, синий — действия и выбор, зелёный — успех |
| «Дилиджан» | `pine` | Песочная бумага, хвойная зелень в кнопках, заголовки с засечками Lora. Названа в честь города в хвойных лесах севернее Севана; до 2026-09-28 называлась «Хвоя на бумаге» (id прежний — выбор пользователей сохраняется) |

- **Где выбрать:** Профиль → Настройки → «Оформление» → «Цветовая тема»: три карточки-образца, нарисованные цветами
  своей темы (светлые или тёмные — как сейчас на экране), у выбранной — рамка и ✓. Рядом — «Светлая или тёмная»
  (Авто / Светлая / Тёмная), она работает для любой темы.
- **Как устроено:** переменные CSS каждой темы — в `src/styles/palettes.css` (три блока на тему: светлый,
  тёмный по выбору и тёмный по системе); тема — атрибут `data-palette` на `<html>`, вид — `data-theme`.
  Кроме цветов тема задаёт скругления (`--radius`, `--radius-lg`), тени, шрифт заголовков (`--font-head`)
  и вид ссылок (`--link-decoration`). Общие для всех: `--accent-pressed` (нажатая главная кнопка),
  `--on-status` (знак в залитом кружке ✓ ≈ ✗), `--plate` (белая плашка под картинками ARASAAC),
  `--lvl-1…6` и `--lvl-text-strong`, `--lvl-5-text` (карта алфавита в статистике).
- Выбор хранится в `settings.palette` прогресса (схема 6) и переносится резервной копией. Те, кто занимался
  до 1.1 (прежняя абрикосовая тема), получают «Матенадаран».
- Чтобы экран не мигал чужими цветами, тема ставится ещё до запуска приложения (скрипт в `index.html`).
- Цвет панели браузера (`theme-color`) — фон текущей темы и вида; в `manifest` и значке приложения —
  цвета «Матенадарана» (значок: тёмный фон, светлая буква Ա; `scripts/make-icons.mjs`).
- Образцы в настройках — `src/app/palettes.ts` (единственное место с кодами цветов вне CSS); тест сверяет их с CSS.
- **Новая переменная** — во все девять блоков `palettes.css` (тест `tests/palettes.test.ts` проверяет полноту,
  совпадение тёмных блоков и контраст). В компонентах — только `var(--…)`.

## 5.6 Доступность

- Все элементы доступны с клавиатуры, видимый фокус.
- Армянский текст размечен `lang="hy"` (правильное чтение экранными дикторами и перенос слов).
- Картинки-примеры имеют подписи (перевод слова).
- Горячие клавиши на компьютере: `1–4` — вариант, `Enter` — проверить/дальше, `Пробел` — перевернуть карточку, `Esc` — выход.

## 5.7 Экранные клавиатуры

Системная клавиатура телефона в заданиях не используется: не нужно переключать раскладку, и она
не закрывает половину экрана непредсказуемым образом. Клавиатура приложения прижата к низу экрана.

**Русская** (задания E06, E07, E09):
- **Упрощённая** — 8–12 крупных клавиш: буквы правильного ответа и «ловушки» в случайном порядке.
  По умолчанию в первых трёх уроках.
- **Полная** — раскладка ЙЦУКЕН (33 буквы, «ё» не нужна) + «стереть» + «Проверить». Клавиши ≥ 28 px
  шириной при 12 клавишах в ряду на экране 360 px, высота ≥ 44 px.
- На компьютере можно печатать с физической клавиатуры. При английской раскладке латинские клавиши
  принимаются по их месту в русской раскладке (J → о, F → а…).

**Армянская** (задание E08 на сложности 4, будущие разделы):
- Только **изученные** буквы + «ловушки», в **алфавитном порядке**, 6–7 клавиш в ряду, крупно (≥ 44 px).
- Ու — одна клавиша (вставляет два знака); և — тоже одна клавиша.
- Переключатель «заглавные / строчные» — только когда в задании важен регистр.
- Физическая клавиатура компьютера для армянских букв не используется (у большинства нет армянской раскладки).
