## Термины

- **Раздел (Section)** — крупная тема курса: «Алфавит», «Чтение», «Первые слова», «Грамматика»…
- **Урок (Lesson)** — порция материала внутри раздела (например, 5 новых букв).
- **Элемент знания (Item)** — то, что запоминается и по чему считается прогресс: буква, слово, фраза.
- **Навык (Skill)** — сторона знания элемента: узнать, вспомнить, прочитать, написать, услышать.
- **Задание (Exercise)** — один вопрос определённого **типа** (выбор варианта, ввод, вставка буквы…).
- **Сессия** — серия заданий, собранная из урока и/или повторений.
