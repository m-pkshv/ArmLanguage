# 8. Открытые вопросы

Для каждого вопроса указана рекомендация — если нет возражений, принимается она.

| # | Вопрос | Варианты | Рекомендация |
|---|---|---|---|
| 1 | UI-фреймворк | Svelte · Preact/React · Vue · чистый TypeScript без фреймворка | **Svelte** — самый компактный код и встроенные анимации. Если планируете сами активно писать код и знаете React — Preact |
| 2 | Картинки к словам | OpenMoji · Twemoji · собственные иллюстрации · фото | **OpenMoji или Twemoji** (SVG, единый стиль), позже заменить на свои по желанию |
| 3 | Рукописный шрифт | готовый шрифт с открытой лицензией · свои SVG букв | Найти шрифт с открытой лицензией для отображения; для прописи (v2) — свои SVG со штрихами. **Нужен ваш пример прописи**, на который ориентироваться (школьная пропись Армении?) |
| 4 | Проверка армянских слов и чтений | носитель языка · словари | **Нужен носитель** (знакомый, преподаватель), хотя бы для финальной проверки ~200 слов |
| 5 | Аудио | записи носителя · синтез речи · без звука в MVP | **Без звука в MVP**, записи носителя — на этапе v2 |
| 6 | Порядок уроков | по алфавиту · по частотности/словам | **По словам** (черновик в [04-content.md](04-content.md#44-порядок-изучения)), алфавитный — в таблице |
| 7 | Строгость проверки по умолчанию | строго · мягко | **Мягко** («т» за «тх» засчитывается с пояснением) |
| 8 | Название и адрес | «Այբուբեն», «Армянский с нуля»… · репозиторий `ArmLanguage` | Название — на ваш выбор; адрес `https://<логин>.github.io/ArmLanguage/` |
| 9 | Аккаунты и синхронизация | не нужны · нужны позже · нужны сразу | **Не нужны в первом релизе**, только экспорт/импорт файла |
| 10 | Западноармянский | не нужен · когда-нибудь | **Не нужен** сейчас; архитектура позволяет добавить вариант языка позже |
