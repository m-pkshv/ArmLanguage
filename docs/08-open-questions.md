# 8. Открытые вопросы

Для каждого вопроса указана рекомендация — если нет возражений, принимается она.

| # | Вопрос | Варианты | Рекомендация |
|---|---|---|---|
| 1 | UI-фреймворк | ✅ **Решено:** Svelte + TypeScript + Vite (выбор технической стороны доверен разработчику) | см. [6.2](06-architecture.md#62-технологии-решено) |
| 2 | Картинки к словам | ✅ **Решено:** Twemoji (CC BY 4.0), запасные — OpenMoji и Wikimedia Commons | см. [4.5](04-content.md#45-картинки) |
| 3 | Рукописный шрифт | ✅ **Решено:** набор SVG школьной прописи с Wikimedia Commons (CC BY-SA 4.0); осталось показать формы носителю | см. [4.6](04-content.md#46-рукописный-вариант) |
| 4 | Проверка армянских слов и чтений | ✅ **Решено:** носителю даётся готовый результат (слова, чтения, рукописные формы) перед релизом. Для удобства проверки делается страница-список всего контента | этап 5 |
| 5 | Аудио | записи носителя · синтез речи · без звука в MVP | **Без звука в MVP**, записи носителя — на этапе v2 |
| 6 | Порядок уроков | по алфавиту · по частотности/словам | **По словам** (черновик в [04-content.md](04-content.md#44-порядок-изучения)), алфавитный — в таблице |
| 7 | Строгость проверки по умолчанию | строго · мягко | **Мягко** («т» за «тх» засчитывается с пояснением) |
| 8 | Название и адрес | «Այբուբեն», «Армянский с нуля»… · репозиторий `ArmLanguage` | Название — на ваш выбор; адрес `https://<логин>.github.io/ArmLanguage/` |
| 9 | Аккаунты и синхронизация | ✅ **Решено:** в MVP — хранилище браузера + экспорт/импорт; в v2 — вход через Google и бесплатная облачная база | см. [6.9](06-architecture.md#69-прогресс-и-хранение) |
| 10 | Западноармянский | не нужен · когда-нибудь | **Не нужен** сейчас; архитектура позволяет добавить вариант языка позже |
