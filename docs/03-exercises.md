# 3. Каталог типов заданий

Каждый тип задания — отдельный модуль с единым интерфейсом (см. [архитектуру](06-architecture.md#67-типы-заданий-как-плагины)).
Новые типы добавляются без изменения остального кода. Здесь описаны типы для раздела «Алфавит».
Многие из них (ввод, выбор, картинка → слово) пригодятся и в будущих разделах со словами.

Для каждого типа указаны:
- **навык**, который тренирует задание;
- **сложность** от 1 до 5 (по ней движок выбирает задания под текущий уровень знания);
- **ввод** — как отвечает пользователь.

---

## Уровень «Знакомство»

### E01. Знакомство с буквой (`letter-intro`) [MVP]
- **Навык:** нет (не оценивается). **Сложность:** 0.
- Экран-презентация новой буквы: печатная и рукописная форма, название, звук, подсказка,
  2–3 слова с картинками. Кнопка «Понятно» → следующая буква урока.
- Показывается при первом появлении буквы в уроке.

---

## Уровень «Узнавание» (выбор из вариантов)

### E02. Буква → звук (`letter-to-sound`) [MVP]
- **Навык:** узнавание. **Сложность:** 1.
- Показана буква → выбрать из 4 вариантов её чтение русскими буквами.
- **Неправильные варианты:** в первую очередь пара буквы (для Թ это «т»), затем буквы текущего урока,
  затем любые изученные.

### E03. Звук → буква (`sound-to-letter`) [MVP]
- **Навык:** узнавание. **Сложность:** 1.
- Показан звук («дз») + описание → выбрать одну из 4 армянских букв.

### E04. Картинка → буква (`picture-to-letter`) [MVP]
- **Навык:** узнавание в слове. **Сложность:** 2.
- Картинка + армянское слово с пропуском на месте изучаемой буквы: `🐟 _ուկ` → выбрать букву (Ձ).
- Под картинкой — перевод («рыба») и чтение с пропуском («_ук»). На высоких уровнях чтение скрыто.

### E05. Найди пары (`match-pairs`) [MVP]
- **Навык:** узнавание. **Сложность:** 1–2.
- Сетка 5×2: слева буквы, справа звуки (или рукописные ↔ печатные, или буквы ↔ картинки).
  Нужно соединить пары нажатиями. Ошибочная пара подсвечивается и «отпускается».
- Засчитывается по каждой букве отдельно.
- Размер поля: 5 пар на телефоне, 6 на планшете и компьютере. Показываются время и число ошибок,
  лучший результат сохраняется.

## Уровень «Воспроизведение» (ввод ответа)

### E06. Карточка с вводом (`letter-type-sound`) [MVP]
- **Навык:** воспроизведение. **Сложность:** 3.
- Показана буква → пользователь **сам набирает её звук русскими буквами** на экранной клавиатуре.
- **Экранная клавиатура** — русский алфавит (раскладка ЙЦУКЕН, 33 клавиши + «стереть» + «Проверить»).
  Системная клавиатура телефона не вызывается: не нужно переключать раскладку. На компьютере можно
  печатать и с физической клавиатуры.
- [Настройка] «Упрощённая клавиатура» для начинающих: только ~12 букв — правильные и «ловушки».
- **Проверка** — см. [правила проверки ввода](#правила-проверки-ввода):
  `Թ` → «тх» = верно; «т» = почти (в «мягком» режиме засчитывается, но объясняется придыхание).
- Кнопка «Не знаю» — показывает ответ, считается ошибкой без штрафа к серии.

### E07. Прочитай слово (`word-type-reading`) [MVP]
- **Навык:** чтение. **Сложность:** 4.
- Армянское слово (+ картинка как подсказка на уровнях 4, без картинки на уровне 5) →
  набрать чтение русскими буквами: `ձուկ` → «дзук».
- Засчитывается по каждой букве слова: ошибка отмечается на конкретной букве
  («ձ прочитано как „з“ — это „дз“»).

### E08. Вставь армянскую букву в русское слово (`ru-word-insert`) [MVP]
- **Навык:** воспроизведение (звук → буква). **Сложность:** 2–4.
- Показано **русское слово** с картинкой, одна (на высоких уровнях — несколько) русских букв
  заменены пропуском: `ма_ина 🚗` → вставить армянский аналог звука «ш» → `Շ`.
- Уровни:
  - 2 — выбор из 4 армянских букв, пропуск один;
  - 3 — выбор, пропусков 2–3 (`_а_ина` → Մ, Շ);
  - 4 — ввод на **армянской экранной клавиатуре** (только изученные буквы + ловушки).
- Если у русского звука несколько армянских аналогов («т» → Տ или Թ, «р» → Ր или Ռ,
  «о» → Օ или Ո), засчитывается **любой** из них, и показывается пояснение.
- Звуки без армянского аналога (щ, ъ, ь) не выбираются как пропуск.
- Буквы «е, ё, ю, я» выбираются только с пояснением («ю» → `յու`), на уровне 3+.
- Сопоставление русских звуков и армянских букв — в [04-content.md](04-content.md#соответствие-русских-и-армянских-звуков).

### E09. Смешанное чтение (`mixed-reading`) [MVP]
- **Навык:** чтение. **Сложность:** 2–5 (растёт автоматически).
- Русское слово или фраза, где **изученные** буквы заменены армянскими:
  если изучены Ա и Մ: `Մամա мыла рամу`; к концу раздела: `Մամա մըլա րամու`.
- Пользователь набирает, что написано, на русской клавиатуре (или выбирает из вариантов на уровне 2).
- Тексты берутся из списка простых русских слов и фраз; замена букв генерируется автоматически
  по соответствию звуков и списку изученных букв.
- **Правила замены:**
  - заменяется только буква, чей армянский аналог уже изучен;
  - если у звука два аналога, берётся основной: т → Տ, п → Պ, к → Կ, ч → Ճ, ц → Ծ, р → Ր, х → Խ, о → Օ, е → Ե
    (в начале слова «е» не заменяется, потому что Ե там читается «йе»);
  - «дж» → Ջ и «дз» → Ձ заменяются целиком; «ю», «я», «щ», «ъ», «ь» остаются русскими;
  - слово, в котором замена даст неоднозначное чтение, не используется.
- Нажатие на армянскую букву показывает подсказку; с подсказкой задание засчитывается как «почти».

## Уровень «Различение»

### E10. Пары-ловушки (`confusable-pair`) [MVP]
- **Навык:** различение. **Сложность:** 3.
- Два типа путаницы:
  - **по звуку:** Տ/Թ, Պ/Փ, Կ/Ք, Ճ/Չ, Ծ/Ց, Ռ/Ր, Ո/Օ, Ե/Է, Խ/Հ, Ղ/Գ;
  - **по виду:** ո/ս, դ/ղ/պ, ե/է, գ/զ/ց, Հ/Յ (заглавные) и т.п. (список уточняется при подготовке контента).
- Задание: слово с этой буквой + 2 варианта написания (`տուն` / `թուն`) → выбрать правильное.
  Или: 6 похожих букв → нажать все `ս`.
- Используется в уроках (когда изучены обе буквы пары) и в отдельном **тренажёре пар-ловушек**
  (см. [02-features.md](02-features.md#пары-ловушки)). Путаницы из всех заданий автоматически
  предлагаются в тренажёре.
- [v2] Со звуком: услышать слово → выбрать написание.

---

## Уровень «Рукописный шрифт»

### E11. Рукописная ↔ печатная (`handwriting-match`) [MVP]
- **Навык:** рукописный вариант. **Сложность:** 3.
- Показана рукописная буква → выбрать печатную (или наоборот).
- Во всех остальных заданиях можно включить рукописный шрифт (настройка сессии) —
  тогда навык «рукописный» тоже получает очки.

### E12. Пропись (`handwriting-trace`) [v2]
- **Навык:** письмо. **Сложность:** 3–5.
- Шаг 1: анимация порядка написания. Шаг 2: обвести пальцем по контуру. Шаг 3: написать самому.
- Проверка — сравнение траектории с эталоном (простое, без ИИ); самооценка «получилось / нет».

---

## Уровень «На слух» [v2]

### E13. Услышь → выбери (`audio-to-letter`)
- Звучит буква или слово → выбрать букву / написание из 4 вариантов.

### E14. Скоростной раунд (`speed-round`)
- 60 секунд, буква → звук на выбор из 2 вариантов. Рекорд сохраняется.

## Правила проверки ввода

Используются в E06, E07, E09 и будущих заданиях с вводом.

1. **Нормализация:** нижний регистр, `ё → е`, пробелы по краям убираются, двойные пробелы схлопываются.
2. У каждой буквы/слова в контенте есть:
   - `canonical` — эталонное чтение («тх»);
   - `accept` — тоже полностью верные варианты;
   - `partial` — «почти»: засчитывается в мягком режиме, с пояснением.
3. Для слов списки `accept`/`partial` **генерируются автоматически** из правил для букв
   (придыхание не написано → partial; «р» вместо «рр» → partial; «е»/«о» вместо начального «йе»/«во» →
   partial), вручную указываются только исключения.
4. Результат проверки: `correct` / `partial` / `wrong`, плюс список **ошибок по буквам**
   (какая буква прочитана неверно и как) — для объяснения и для статистики путаниц.
5. Опечатки не прощаются в заданиях на буквы (каждая буква важна). В будущих разделах со словами
   может быть допуск «1 опечатка → почти».

## Как движок выбирает задание

1. Берёт элемент (букву) из очереди сессии: новые буквы урока + буквы, которым пора на повторение.
2. Смотрит уровень знания буквы по навыкам и подбирает тип задания со сложностью «на ступеньку выше»
   самого слабого навыка.
3. Не повторяет один и тот же тип больше 2 раз подряд.
4. Ошибочные задания возвращает в конец сессии.
