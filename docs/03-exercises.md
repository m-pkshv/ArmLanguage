# 3. Каталог типов заданий

Каждый тип задания — отдельный модуль с единым интерфейсом (см. [архитектуру](06-architecture.md#67-типы-заданий-как-плагины)).
Новые типы добавляются без изменения остального кода. Здесь описаны типы для раздела «Алфавит»;
многие (выбор, ввод, картинка → слово) пригодятся и в будущих разделах.

Для каждого типа указаны **навык**, **сложность** (1–5, по ней движок подбирает задания под уровень знания)
и **версия** ([V1], [V2], [Позже] — см. [02-features.md](02-features.md#метки-версий)).

## Навыки

| Навык | Что значит | Основной? |
|---|---|---|
| `recognize` — узнавание | видишь букву — узнаёшь среди вариантов | **да** |
| `recall` — вспоминание | сам вспоминаешь звук или букву без подсказки вариантов | **да** |
| `read` — чтение | читаешь букву внутри слова | да, с V2 |
| `case` — заглавные/строчные | связываешь заглавную и строчную форму | нет |
| `handwriting` — рукописные | узнаёшь рукописную форму | нет |
| `discriminate` — различение | не путаешь с похожей буквой | нет |
| `listen` — на слух | узнаёшь букву по звуку | нет (позже) |

«Выучена» считается только по основным навыкам (см. [2.5](02-features.md#25-когда-алфавит-выучен)).
Дополнительные навыки влияют на подбор заданий и видны в статистике, но не задерживают прохождение курса.

## Узнавание (выбор из вариантов)

### E02. Буква → звук (`letter-to-sound`) [V1]
- Показана буква (заглавная или строчная) → выбрать из 4 вариантов её чтение русскими буквами.
- **Неправильные варианты:** сначала пара-ловушка буквы (для Թ это «т»), затем буквы текущего урока,
  затем любые изученные.

### E03. Звук → буква (`sound-to-letter`) [V1]
- Показан звук («дз») с описанием и кнопкой 🔊 → выбрать одну из 4 армянских букв.

### E15. Заглавная ↔ строчная (`case-match`) [V1]
- Показана заглавная → выбрать строчную из 4 вариантов (или наоборот).
- Неправильные варианты подбираются **похожими по виду**, особенно для букв, у которых формы сильно различаются
  (Ա/ա, Ղ/ղ, Ռ/ռ, Ճ/ճ…).
- Для Ու (две буквы-знака) и և (нет заглавной формы) — с пояснением: в начале предложения пишут «Ու», «Եվ».

### E04. Картинка → буква (`picture-to-letter`) [V1]
- Картинка + армянское слово с пропуском на месте изучаемой буквы: `🐟 ձ_կ` → выбрать букву (Ու).
- Под словом — **чтение по буквам с выделенным пропущенным звуком** и перевод: [дз**у**к] — рыба.
  Вопрос: «Какая буква даёт звук „у"?». Слов пользователь ещё не знает, поэтому задание должно решаться
  знанием алфавита, а не словаря (замечание по проверке на телефоне, 2026-09-26).
- Среди вариантов нет букв, которые читаются так же, как пропущенный звук (Ո и Օ — «о», Խ и Հ — «х»),
  иначе правильных ответов было бы два.

### E05. Найди пары (`match-pairs`) [V2]
- Поле из 5 пар: слева буквы, справа их пары. Виды пар: **буква ↔ звук** (основной), **заглавная ↔ строчная**,
  **печатная ↔ рукописная** (строчные буквы; только в «Практике»). «Буква ↔ картинка» решено не делать:
  слов пользователь не знает, и по картинке букву не угадать.
- Нажать карточку в одной колонке, потом её пару в другой (порядок любой). Верная пара становится зелёной
  и бледнеет, ошибочная на полсекунды краснеет, выбор сбрасывается. Ни одна пара не стоит напротив друг друга.
- На одном поле нет двух букв с одинаковым звуком (Ո и Օ — «о», Խ и Հ — «х»), у և нет заглавной — в
  «заглавных» её нет.
- Сверху секундомер и число ошибок; в конце — время и «Новый рекорд!» / «Рекорд: 0:12».
  **Рекорд** — лучшее время одного поля без ошибок, отдельно для каждого вида пар (хранится в прогрессе, `games`).
- Засчитывается по каждой букве: нашли с первого раза — верно, ошиблись — неверно (навык по виду пар:
  узнавание, заглавные/строчные, рукописные). Если букву соединили с её парой-ловушкой — это путаница.
  Раунд целиком засчитывается как «верно» или «почти» и не повторяется в конце занятия.
- **Где:** разминка в начале урока со 2-го урока (буквы прошлых уроков, «буква ↔ звук»); экран
  «Найди пары» в «Практике» (выбор вида пар, три поля подряд, сначала слабые буквы); кнопка
  «Поиграть в „Найди пары“» на главном экране, когда повторять нечего.
- Код: `src/exercises/matchPairs.ts`, вид — `views/MatchView.svelte`, экран — `src/app/screens/Match.svelte`.

## Вспоминание (ввод ответа)

### E06. Карточка с вводом (`letter-type-sound`) [V1]
- Показана буква → пользователь **сам набирает её звук русскими буквами**.
- **Экранная русская клавиатура** (описание — [05-ui-mobile.md](05-ui-mobile.md#57-экранные-клавиатуры)):
  - в первых трёх уроках по умолчанию **упрощённая**: 8–12 клавиш (правильные буквы и «ловушки»);
  - дальше полная, ЙЦУКЕН. Переключается в настройках.
- Проверка — см. [правила проверки ввода](#правила-проверки-ввода): `Թ` → «тх» = верно; «т» = почти.
- Кнопка «Не знаю» показывает ответ и считается ошибкой.

### E08. Вставь армянскую букву в русское слово (`ru-word-insert`) [V1]
- **Русское слово** с картинкой, одна или несколько букв заменены пропуском:
  `ма_ина 🚗` → вставить армянскую букву со звуком «ш» → `Շ`.
- Сложность:
  - 2 — выбор из 4 армянских букв, один пропуск;
  - 3 — выбор, 2–3 пропуска (`_а_ина` → Մ, Շ);
  - 4 — ввод на **армянской экранной клавиатуре** (только изученные буквы + ловушки).
- Если у русского звука два армянских аналога («т» → Տ/Թ, «р» → Ր/Ռ, «о» → Օ/Ո), засчитывается **любой**,
  с пояснением разницы.
- Звуки без армянского аналога (щ, ъ, ь) пропуском не становятся. «ю», «я» — только со сложности 3 и с пояснением («ю» → `յու`).
- Соответствие звуков — [04-content.md](04-content.md#соответствие-русских-и-армянских-звуков).

### E07. Прочитай слово (`word-type-reading`) [V2]
- Армянское слово из **знакомых** букв (обязательно с тренируемой буквой) → набрать его чтение на полной
  русской клавиатуре: `ձուկ` → «дзук». Упрощённой клавиатуры нет — по её клавишам можно угадать ответ.
- Слов пользователь не знает, поэтому проверяется **чтение по буквам**. Пока навык «чтение» у буквы
  невысокий (коробка 0–2), над словом картинка и перевод; дальше — только слово. Сначала слова до 4 букв,
  потом до 6, потом любые.
- Нажатие на букву показывает её чтение — эта буква засчитывается как «почти» (как в E09).
- Проверка (`src/core/checking/word.ts`): ответ сопоставляется с буквами слова (для каждой буквы — какой кусок
  ответа ей достался). Верно: произношение («хындзор») и чтение буква за буквой без «ы» («хндзор», с пояснением).
  «Почти» — по правилам букв («т» вместо «тх», «е» вместо начального «йе»). «ы» можно вставлять только между
  согласными. Слово-исключение, прочитанное по правилу («йем» вместо [эм]), — «почти», с пояснением.
- После ответа под каждой буквой — её чтение: зелёным верно, жёлтым «почти», красным ошибка
  (и что было написано). В пояснении: «ձ прочитано как „з“ — это „дз“», «կ пропущено — это „к“».
- Навык «чтение» засчитывается каждой букве слова отдельно. Если букву прочитали как её пару-ловушку
  (ո как «с»), это записывается в путаницы.
- **Где:** последнее задание каждого урока (слово с новой буквой); в обычных занятиях и «Повторении» —
  изредка, когда букву уже вспоминают уверенно (коробка вспоминания 2+); плитка «Прочитай слово» в
  «Практике» (10 слов); в «Своей тренировке».
- Позже — в итоговом тесте с замером времени (пункт 7 плана V2).

## Чтение и различение

### E09. Смешанное чтение (`mixed-reading`) [V2]
- Русское слово или фраза, где **изученные** буквы заменены армянскими:
  изучены Ա и Մ → `մամա մылա рամу`; к концу раздела → `մամա մըլա րամու`.
- Ответ: выбрать правильное прочтение из трёх. Неправильные варианты — та же фраза, где одна армянская
  буква «прочитана» как похожая на неё (идём → игём). Отдельное слово на высоком уровне набирается на клавиатуре.
- Нажатие на армянскую букву показывает её чтение; с подсказкой верный ответ засчитывается как «почти».
- Формы: слова и фразы, а когда знакомо от 25 букв — ещё и мини-тексты (2–3 предложения).
- Где: 1–2 задания в конце каждого урока (на новые буквы) и плитка «Смешанное чтение» в «Практике» (10 заданий).
- Тексты: `content/ru/words.json` и `content/ru/phrases.json`. Буквы, которых в текстах нет (сейчас Խ — «х»),
  в это задание не попадают.
- **Правила замены:**
  - заменяется только буква, чей армянский аналог уже изучен;
  - если аналогов два, берётся основной (первый в `content/rules/ru-hy.json`): т → Տ, п → Պ, к → Կ, ч → Ճ,
    ц → Ծ, р → Ր, х → Խ, о → Օ, е → Ե (в начале слова Ե читается «йе» — как и русское «е»);
  - «дж» → Ջ, «дз» → Ձ заменяются целиком; «ю», «я», «щ», «ъ», «ь» остаются русскими;
  - «ы» → Ը — **игровое приближение**: в армянском Ը — краткий неясный гласный, а не русское «ы».
    Это оговаривается в подсказке при первом появлении;

### E10. Пары-ловушки (`confusable-pair`) [V2]
- Путаница **по звуку**: Տ/Թ, Պ/Փ, Կ/Ք, Ճ/Չ, Ծ/Ց, Ռ/Ր, Ո/Օ, Ե/Է, Խ/Հ, Ղ/Գ;
  **по виду**: ո/ս, դ/ղ/պ, ե/է, գ/զ/ց, Հ/Յ (заглавные) и др. (список уточняется при подготовке контента).
- **Написание** (для пар по звуку): картинка, чтение слова по буквам с выделенным звуком и перевод,
  два написания (`ճուտ` / `ճութ`) → выбрать правильное. Чтение делает задание решаемым без знания слов.
  Слова, где обе буквы читались бы одинаково (Խ/Հ — «х», Ո/Օ в середине слова — «о»), не используются.
- **Сетка** (для пар по виду, а также Խ/Հ): 8 клеток, из них 3–4 нужные буквы → отметить все и нажать «Готово».
- Путаницы из всех заданий копятся в прогрессе. Пару, спутанную 2 раза и больше, приложение предлагает
  потренировать на главном экране и в итогах занятия.
- Работает в уроках (когда изучены обе буквы) и в тренажёре пар-ловушек ([02-features.md](02-features.md#пары-ловушки-v2)).

## Правила проверки ввода

Используются в E06, E07, E09 и будущих заданиях с вводом.

1. **Нормализация:** нижний регистр, `ё → е`, пробелы по краям убираются, двойные пробелы схлопываются.
2. У каждой буквы и слова в контенте есть `canonical` (эталон), `accept` (тоже верно) и `partial` («почти»:
   засчитывается в мягком режиме, с пояснением).
3. Для слов `accept` и `partial` **генерируются автоматически** из правил для букв:
   - придыхание не написано («т» вместо «тх») → почти;
   - «р» вместо «рр» → почти;
   - «е»/«о» вместо начального «йе»/«во» → почти.
4. **Непроизносимое «ы».** В армянском между согласными часто звучит краткий гласный, который не пишется:
   `խնձոր` — [хындзор], `գրել` — [гырел]. У слова хранится **произношение** (`pronunciation`) с этим звуком:
   - ответ по произношению («хындзор») → верно;
   - ответ «по буквам» без «ы» («хндзор») → **тоже верно**, с пояснением «в живой речи между согласными
     звучит краткое „ы“»: для задания на алфавит важно, что буквы прочитаны правильно.
5. **Исключения.** Слова, которые читаются не по общим правилам, помечаются в контенте, и для них
   произношение задаётся вручную. Пример: формы глагола «быть» (եմ, ենք, եք, են) читаются через «э» —
   [эм], [энк], [эк], [эн], — хотя Ե в начале слова обычно «йе». Ответ «по правилу» («йем») → почти,
   с объяснением исключения. Список исключений составляется и проверяется с носителем.
6. **Результат:** `correct` / `partial` / `wrong` и список **ошибок по буквам** (какая буква прочитана неверно
   и как) — для объяснения и для статистики путаниц.
7. Опечатки в заданиях на буквы не прощаются: каждая буква важна.
8. **Физическая клавиатура компьютера.** Если включена английская раскладка, латинские клавиши
   принимаются по их месту в русской раскладке (J → о, F → а, `;` → ж…) — не нужно переключать язык.

## Как движок выбирает задание

**Уровень навыка** = номер коробки интервального повторения (0–5, см. [2.6](02-features.md#26-прогресс-и-интервальное-повторение-v1)).
Код — `src/session/select.ts`.

1. Взять букву из очереди занятия: новые буквы урока, буквы с наступившим сроком повторения, немного трудных.
2. **Какой навык тренировать:** узнавание, если буква новая (коробка узнавания 0) или вспоминание не отстаёт от
   узнавания; иначе — вспоминание. Так сначала учимся узнавать букву, потом — вспоминать сами.
3. **Какое задание** — по коробке выбранного навыка:

| Навык | Коробка 0 | Коробка 1 | Коробка 2 | Коробка 3+ |
|---|---|---|---|---|
| Узнавание | E02, E03 | E02, E03, E04 | E04, E03, E02 | E04, E03, E02 |
| Вспоминание | E08 (выбор из 4) | E08 (выбор из 4) | E06, E08 (выбор из 6) | E06, E08 (армянская клавиатура) |

4. С вероятностью 3 к 10 (когда буква уже узнаётся) — дополнительный навык: E15 «заглавная ↔ строчная»,
   E10 «пары-ловушки» (если вторая буква пары знакома) или E07 «прочитай слово» (если букву уверенно
   вспоминают — коробка 2+ — и есть слово из знакомых букв).
   Кроме того, в уроке, где приходит вторая буква пары по звуку, сразу есть задание E10 на эту пару.
5. Тип, который не подходит букве, пропускается: например, для E08 нужен русский звук с этой буквой
   (у Ղ, Հ, Ձ, և его нет), для E15 — заглавная форма (у և её нет).
6. Не давать один и тот же тип больше 2 раз подряд. Выбранные типы сохраняются вместе с занятием,
   поэтому после перезагрузки страницы показывается то же задание.
7. Задание с ошибкой вернуть через 4 шага (не больше 6 повторов за занятие; в итоговом тесте — без повторов).

Карточка с вводом (E06) использует упрощённую клавиатуру в первых трёх уроках и пока знакомых букв меньше 15.
